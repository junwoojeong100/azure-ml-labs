# Straightforwardness 평가

**2026-09-17 전체 가이드 점검 결과: 95/100 유지 — S01–S19 충족, 실제 학습자 수행 평가 U20은 미실시.**

이 점수는 **명시한 기준에 대한 자체 문서 평가**이지, 독립 평가자나 학습자 실험으로 측정한 객관적 사용성 점수가 아닙니다. 문서만 짧게 줄이는 대신 “무엇을 열고, 어디서 실행하고, 무엇을 보면 다음으로 가는가”를 확인합니다.

**점검 범위:** Markdown 8개(README 1개 + `docs/` 7개), Notebook 1개 전체입니다. 학습자 시작·실습뿐 아니라 강사 준비, 인프라 선택, 문제 해결·정리, 과거 실행 보고서, 이 평가 문서까지 포함합니다. 이 페이지는 실습 절차가 아닌 유지보수 기록입니다.

**표기 원칙:** 가이드의 설명과 Notebook 문구는 **한글·영문만** 사용합니다. 숫자·수식·Markdown/코드 기호는 유지하며, 한자·일본어 등 다른 문자가 섞이면 문서 검사에서 실패합니다. Notebook은 설명 셀과 코드 셀의 문자열을 모두 확인합니다.

## 검증 범위

프로젝트 루트의 로컬 개발 환경에서 **86개 검사가 통과**했습니다. 학습자가 실습 중 실행할 단계는 아닙니다.

```bash
.venv/bin/python -m pytest --disable-warnings tests/test_guide.py \
  tests/test_lab.py::test_studio_notebook_is_valid_and_its_cells_parse
```

| 검사 | 확인 범위 |
|---|---|
| 문서 구조·언어 | 전체 로컬 링크·anchor, 01–07과 하위 단계 18개의 제목·코드 대응, Bash 문법, Notebook 형식·구문, 한글·영문 외 문자 혼입 차단 |
| 흐름·이름·출력 | 03 실패 실험과 04 배포 원본의 관계, Data/Job/Models 대응표, 신규/재개 CLI의 실제 이름 출력, Python/JSON 표기, 실행 중 대기 안내 |
| 설정 일치 | VM SKU·노드 범위·유휴 시간·배포 VM 수·인증 방식을 YAML/SDK 기본값과 대조 |
| 준비 실패 경로 | ZIP 경로·파일 누락, Python 버전·설치·로그인 실패 후 후속 실행 차단 |
| 강사 명령 대역 실행 | 기존/불명확한 RG, Azure 조회·생성 오류, 잘못된 사용자 ID·역할 할당 오류, Compute 생성 실패 시 중단 및 학습자 할당 인자 |
| 정리·전달 | 수동 삭제 대상 누락 시 중단, 조회/삭제 분리, Terminal 없는 정리의 연결·순서·범위, runner·Studio 게시에 가이드와 증빙 파일 포함 |
| Notebook API 대역 실행 | 일반 진행과 kernel 재시작 지점 12개. 실제 이름 출력, 의도된 오류 2개, 중복 제출 방지, 전환·롤백, 응답 불일치 시 완료 표시 금지 |

추가한 회귀 검사 11개는 수정 전 가이드에서 실패하고 개선 후 통과함을 확인했습니다. 별도로 Notebook 재개 검사 4개를 추가했습니다. 출력문을 제외한 Notebook 코드의 구문 트리를 이전 버전과 대조해 처리 로직이 바뀌지 않은 것도 확인했습니다.

Azure 명령의 대역 실행은 **순서·인자·오류 전파 검사**입니다. 실제 구독의 권한·쿼터·네트워크가 준비됐음을 증명하지는 않습니다. 새 Studio 정리 안내의 endpoint 삭제·Instance 중지 경로는 [공식 절차](troubleshooting.md#terminal-없이-정리하기)와 대조했으며, 실제 UI 클릭을 수행한 것은 아닙니다.

## 이전 개선과의 구분

2026-09-16에는 학습자/강사 문서를 분리하고 Notebook·CLI의 01–07, 재개 ID, 의도된 실패, 응답 비교를 정리했습니다. 당시 로컬 검사 41개가 통과했고, 병합된 의존성 업데이트의 설치 호환성을 보완했습니다.

2026-09-17의 앞선 점검에서는 인프라 선택 안내, 동일 브랜치 ZIP, 하위 단계 18개, 공유 Cluster 종료 기준을 보완했고 선택 검사 39개가 통과했습니다. 그다음 점검에서는 한글·영문 표기, 준비 실패 시 중단, 학습자 역할·Instance 할당, 직접/기본 응답 비교, 게시본의 증빙 JSON 포함을 보완했고 71개가 통과했습니다. **이 수치는 이전 점검의 기록**이며 이번 전체 점검의 테스트 수가 아닙니다.

## 평가의 한계

이번 작업에서는 Azure 리소스 생성·학습·추론·삭제를 다시 수행하지 않습니다. 기존 실제 실행 결과는 별도 기록으로 유지합니다. Studio 파일 공유의 이전 게시본은 자동 업데이트되지 않으므로 학습자 시작 안내는 최신 ZIP을 별도 폴더에 준비하도록 설명합니다.

문서 점수를 실제 학습자 경험으로 확인하려면 U20을 별도로 수행해야 합니다. 그 전에는 “실사용자 평가 95점” 또는 “완전한 무중단 실행을 새로 실증했다”고 표현하지 않습니다.
